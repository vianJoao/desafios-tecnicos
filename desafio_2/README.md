# Exibir conteúdo do editorias.csv
Prompt:
Desenvolva uma rota Flask que carregue o arquivo editorias.csv utilizando a biblioteca pandas e exiba os dados em uma tabela HTML formatada. O template deve ser renderizado com Jinja2 e conter uma estrutura básica com cabeçalho, corpo e estilos de tabela. Forneça o código completo da rota e do template.

# Consumir a API https://catfact.ninja/fact
Prompt:
Implemente uma rota Flask que realize uma requisição GET para https://catfact.ninja/fact utilizando a biblioteca requests. Extraia o campo fact da resposta JSON e exiba o conteúdo em uma página HTML utilizando um template. Adicione tratamento de erro básico para falha na requisição. Forneça o código da rota, template e resposta formatada.

# Página com horário local e interação visual
Prompt:
Crie uma página HTML5 com JavaScript que exiba o horário local do cliente em tempo real. O horário deve ser atualizado a cada segundo. Aplique um efeito visual que altere a cor do texto quando o mouse passar sobre ele, utilizando CSS ou JavaScript. Forneça o HTML completo, com o script embutido ou externo.

# Página com acesso à câmera e captura de imagem
Prompt:
Implemente uma página HTML5 com JavaScript que utilize a API getUserMedia() para acessar a câmera do usuário. Exiba o vídeo em tempo real na tela. Insira um botão que, ao ser clicado, capture uma imagem do vídeo usando um elemento <canvas> e exiba a imagem capturada como preview na mesma página. Forneça o HTML e JavaScript completos.

# Prompt de contexto utilizado no início da interação com a IA
Você é um assistente para desenvolvimento web. O projeto utiliza Python com Flask no back-end e HTML5/JavaScript no front-end. Não forneça explicações, apenas código funcional e direto, pronto para ser integrado em um projeto real. Siga boas práticas, escreva código limpo e modular. Separe claramente trechos de código por linguagem.

# Dificuldades encontradas ao utilizar IA generativa
Apesar da agilidade na geração de código, a IA pode apresentar as seguintes limitações:
Gerar soluções genéricas que exigem adaptação ao contexto do projeto
Utilizar bibliotecas ou padrões desatualizados
Ignorar pequenos detalhes técnicos como permissões de câmera, tratamento de erros HTTP, entre outros
Necessidade constante de validação manual e testes

Conclusão
A IA generativa, quando bem instruída com prompts claros e objetivos, é uma ferramenta poderosa para acelerar o desenvolvimento. No entanto, exige conhecimento técnico para validar, adaptar e manter o código gerado. Ela é mais eficiente como suporte ao desenvolvedor do que como solução completa e autônoma.
